Help chat

Answers from the company's own articles and cites the source. A confidence check on every answer means questions the docs don't cover go to a person, along with the conversation so far.

Agent desk

Sorts the inbox by what matters: outages and security first, then teams that are blocked or losing money, then how-to questions. Churn risk is flagged so the right person can step in early. Each ticket opens like a Jira Service Management issue, with the reply already drafted.

Macro library

Consistent, on-policy replies the whole team can use, exportable as CSV for most helpdesks. The triage step picks the right macro and fills in the specifics.

A request, end to end

  1. Ask. The customer asks the Keeper in the help portal. If the docs cover it, they're done.
  2. Raise a request. If not, they contact support. Matching articles appear while they type, and "This answered my question" closes it with no ticket.
  3. Triage. The request lands in Live requests as PH-101: tagged, prioritized, with an SLA clock from the plan's response time (Business 4h, Team 1 business day, Free 2 business days; outages and security right away). Emails to support@ arrive the same way.
  4. Work it. The agent reads the thread, adds internal notes, shares a help article, edits the drafted reply, and sends. Status: Waiting for customer.
  5. Close the loop. The customer sees the reply under My requests, answers back (it returns to the queue) or marks it resolved.

Runs four ways

  • Offline rules: keyword rules and macros, free and instant, no AI needed.
  • Cloud AI on this page: Llama 3.3 70B on Cloudflare Workers AI, inside the free daily allowance, with per-visitor limits.
  • Local model: runs on the business's own computer through Ollama, so ticket data never leaves the building.
  • Claude API: the most accurate drafts, for a few cents per ticket.

Measured, not guessed

Every ticket set has hand-checked labels, so accuracy is scored rather than eyeballed. The rules engine was written alongside the sample tickets, so its score there is a ceiling. The unseen set shows how keyword rules hold up on new phrasing, and is the bar the AI engine has to beat.
